# Printable Book implementation roadmap

This repository is being delivered in gated phases. Only the current phase may be implemented until its verification and architecture-review gate has passed.

1. Phase 0 — Architecture baseline, GitHub setup, CI.
2. Phase 1 — Reusable domain and technical foundation.
3. Phase 2 — Core printable-book processing MVP.
4. Phase 3 — Desktop MVP.
5. Phase 4 — Batch processing, brand rules, and confirmed extensions.
6. Phase 5 — Production hardening and KDP validation.
7. Phase 6 — Controlled release.

Detailed phase checklists are maintained in the local planning workspace and are intentionally not committed with the application source.
